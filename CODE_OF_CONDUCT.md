# Code of Conduct

Danmante is a healthcare-adjacent project; contributors are expected to act with the same care toward each other as the platform requires toward patients: respectful, honest, and safety-first.

- Be respectful in issues, PRs, and discussions.
- No harassment, discrimination, or personal attacks.
- Disagreements about clinical-safety or security matters should be resolved with evidence and documentation (see `docs/architecture/DECISION_LOG.md`), not authority alone.
- Report conduct violations to the maintainers privately.
