# Danmante Roadmap

This roadmap reflects the current product maturity and the realistic path toward safer, more robust healthcare-access infrastructure.

## Phase 1 — Public foundation

Goal: establish a trust-building public presence and a clear engineering narrative.

- complete the public website and navigation model
- finalize GitHub Pages deployment and custom domain configuration
- improve project documentation and contribution flow
- document current implementation limits and safety boundaries

## Phase 2 — Operational logic

Goal: move from public messaging to production-quality operational rules.

- formalize jurisdiction-aware access controls
- define onboarding, review, and verification workflows
- add broader security and safety governance checks
- strengthen API and schema boundaries for future integration

## Phase 3 — Compliance and clinical readiness

Goal: prepare for regulated operational environments and healthcare review.

- deepen review of clinical safety and patient-impact boundaries
- align decision flows with legal and regulatory constraints
- validate professional and pharmacy verification models
- prepare for external audits and governance feedback

## Phase 4 — Scale with discipline

Goal: expand carefully into supported jurisdictions and operational scenarios.

- implement multilingual and regional expansion paths
- define cross-border and jurisdiction-specific governance rules
- ensure operational maturity before scaling service exposure
- maintain a documented safety-first product philosophy

## Current status

Danmante remains in a pre-production, foundation-building phase. The project is intentionally transparent about what is implemented and what requires external review before regulated deployment.
