# Threat Model

## Scope

This repository is a foundational digital health platform template. It is not a production deployment.

## Top risks

- Unauthorized access to patient or professional data
- Jurisdiction bypass or unsafe clinical workflow execution
- Fraudulent professional verification
- Payment fraud or abuse
- Supply-chain and dependency issues

## Controls to implement before production

- Strong auth and MFA
- Server-side authorization
- Rate limiting and abuse detection
- Audit logging
- Dependency auditing
- Secret management and rotation
- Backup and recovery testing
