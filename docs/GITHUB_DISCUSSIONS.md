# GitHub Discussions guide

GitHub Discussions is the recommended place for community conversation around design questions, roadmap feedback, safety concerns, and contributor ideas.

## Recommended categories

Create categories such as:

- Announcements
- General
- Ideas
- Q&A
- Roadmap
- Safety and governance

## Suggested usage

- use Discussions for broader conversation and community feedback
- use Issues for concrete bugs, implementation tasks, and repair requests
- keep public safety or vulnerability concerns out of open discussion and follow the security reporting flow instead

## Activation steps

1. Open the repository on GitHub.
2. Go to Settings → Features.
3. Enable Discussions.
4. Create categories that match the project’s audience and governance model.
5. Pin the roadmap or getting-started discussion for new contributors.

## Community expectations

- stay respectful and constructive
- separate product ideas from safety claims
- be explicit about what is implemented vs still under review
- keep conversations rooted in real project constraints and legal boundaries
